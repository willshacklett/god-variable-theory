# EXP002 — Partial Observation Recovery

## Question

Can an upstream source be reconstructed when only part of the downstream signal is observed?

## Hypothesis

Blind inference can recover the hidden source more effectively than a naive baseline when a moderate fraction of the downstream signal is observed.

## Assumptions

- The forward process remains approximately linear.
- The hidden source is smooth enough to support partial recovery.
- The observation mask is known.

## Forward model

The same one-dimensional advection-diffusion propagation operator from Experiment 001 is used.

## Reconstruction method

Four reconstruction approaches are compared:

- Oracle reconstruction with the true forward model
- Blind reconstruction with jointly inferred forward parameters
- Interpolation-plus-inversion baseline
- Naive baseline

## Masking strategies

- Uniform: observations are retained at uniformly spaced positions.
- Window: observations are retained in one contiguous interval.
- Random: observations are retained with a fixed per-sample probability.

## Evaluation metrics

- RMSE
- Pearson correlation
- Correlation retention
- Spectral information loss
- Parameter-estimation error

## Success criteria

- Full observation approximately reproduces Experiment 001-style performance.
- Reconstruction quality worsens as the observed fraction falls.
- Blind inference outperforms the naive baseline at moderate observation levels.

## Failure criteria

Experiment 002 fails if blind inference does not reliably outperform the naive baseline at 50% observation across source families.

## Results

Results are written to the outputs directory as CSV and image artifacts.

The CSV artifacts contain raw trial rows and independently derived aggregate rows. The aggregate rows are computed from the trial rows after the full benchmark run, rather than being injected or smoothed post hoc.

### Preregistered hypothesis result

For the raw matched-trial comparison at 50% observation, blind inference was evaluated against the naive baseline using paired RMSE differences across matched source-family and seed pairs.

- Mean paired RMSE difference: 0.5693
- 95% bootstrap confidence interval: [0.4420, 0.7184]
- Win rate: 1.0
- Matched pairs: 9

This result is limited to the toy linear model used here, the specific source families, the selected seeds, and the masking configurations evaluated in this benchmark.

### Failure boundary

The benchmark shows a sharp degradation in reconstruction quality at 10% observation, which is a useful failure boundary for interpreting how fragile the recovery becomes under severe masking.

## Lessons learned

This remains a toy linear inverse problem and should not be interpreted as evidence for cosmological claims.
