## Read Status in Scope

| Controlled status | Meaning |
| --- | --- |
| SUPPORTIVE | Supports only the entry's named hypothesis within its evidence scope. Current entries here are synthetic methodology or engineering assertions, not physical GV evidence. |
| MIXED | Some checks work, while important competing checks fail. Not confirmation. |
| NOT SUPPORTIVE | The formulation's stated success criterion was not met. Ties do not support superiority. |
| INVALID / INCONCLUSIVE | Validity failed, or an illustration lacks a valid independent evidential test. Not a supportive result or a valid performance rejection. |
| PENDING | No completed result established; for the three requested IDs, original records/status await verification. |
| HARDWARE READY / NOT RUN | Protocol/software documentation is available; physical completion, assembly and apparatus certification are not established. |

## Provenance and Coverage

Original reports and preregistrations are not overwritten. The
[F2b report](../experiments/GV_FLUID_F2B_RESULTS.md) is explicitly a new
2026-10-05 computational run of frozen code. F2 remains invalid.
Five historical switch failures are grouped in one entry with all failure
approaches preserved in the [failure notes](../experiments/GV_SWITCH_FAILURE_NOTES.md).
Do not mistake its aggregate entry count for five independently replicated trials.

All current experiment Python entry points, preregistration Markdown files, and
fluid result reports have ledger coverage checked by
[integrity tests](../tests/test_research_integrity.py). Foundational operational
modules are not all experiments; dashboard plots and CI longitudinal records
are software metrics. Alternate upstream branches were not merged into the launch
or presented as validated main-branch evidence.

`dataset.paths: []` means no archived dataset in this repository, not that measured
data exist elsewhere. Synthetic datasets are generated by frozen code. A null
reproduction command means no honest executable reproduction can be provided:
obsolete implementation absent, missing protocol, or physical acquisition not run.
An executable computational command does not imply physical replication.

Changing a historical result requires an explicit correction with provenance,
preserving the original, not an unnoticed status edit. New formulations require
new IDs and prospective criteria; see [falsification](FALSIFICATION.md).
